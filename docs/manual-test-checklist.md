# 草泥鸽工具箱 — 手动验证清单

> 用于 build 阶段联调与 verify 阶段验收。每项标注 `[ ]` 未验证 / `[x]` 通过。

## 1. 启动与托盘

- [ ] 启动 exe 后系统托盘出现鸽子图标，无主窗口强制弹出（或首启弹出主面板）
- [ ] 关闭主窗口（×）后程序不退出，托盘仍在
- [ ] 重复启动 exe 只运行一个实例（第二实例提示已在运行）
- [ ] 托盘菜单：显示主面板 / 截图置顶 / 粘贴板 / 取色器 / 关闭全部贴图 / 退出 全部可用
- [ ] 托盘「退出」后进程完全结束，无残留

## 2. 全局热键

- [ ] `Ctrl+Shift+A` 唤起截图置顶
- [ ] `Ctrl+Shift+C` 唤起取色器
- [ ] `Ctrl+Shift+V` 唤起粘贴板面板
- [ ] `Ctrl+Shift+P` 唤起主面板
- [ ] `Ctrl+Shift+Q` 关闭全部贴图
- [ ] 任意前台窗口（浏览器/编辑器/全屏游戏窗口除外）下热键均生效
- [ ] 与其它程序热键冲突时托盘气泡提示，不崩溃

## 3. 截图置顶

- [ ] 截图遮罩覆盖全部显示器（多显示器环境）
- [ ] 框选时实时显示选区宽×高
- [ ] `Esc` 取消截图，无贴图产生
- [ ] 框选 <4×4 像素视为误触，不产生贴图
- [ ] 完成框选后：生成置顶贴图 + 图片已复制到剪贴板
- [ ] 贴图可拖动到任意位置（含跨屏）
- [ ] 滚轮缩放 20%~500%，以鼠标位置为锚点
- [ ] 贴图右键菜单：复制 / 点击穿透 / 保存到文件 / 关闭
- [ ] 点击穿透开启后鼠标可穿过贴图点击下层窗口；关闭后恢复
- [ ] 双击贴图复制图片到剪贴板
- [ ] 保存到文件：默认目录 `~/Pictures/CaoNiGeToolbox/`，PNG 格式
- [ ] 连续截图 21 张时第 21 张被拒绝并气泡提示「贴图数量已达上限」
- [ ] 托盘「关闭全部贴图」一键清理所有贴图

## 4. 贴图边框

- [ ] 6 种预设（无/细线/粗线/虚线/发光/圆角）切换后所有贴图即时刷新
- [ ] 自定义边框颜色（取色器取色/颜色对话框）即时生效
- [ ] 自定义边框粗细即时生效
- [ ] 重启后边框设置保持

## 5. 粘贴板

- [ ] 复制一段文本 → 历史面板出现该文本
- [ ] 复制一张图片 → 历史面板出现大缩略图
- [ ] 连续复制相同内容只保留一条
- [ ] 复制 >20MB 图片不记录且气泡提示
- [ ] 重启应用后历史仍在
- [ ] 搜索框按关键词过滤文本条目
- [ ] 类型筛选：全部 / 文本 / 图片
- [ ] 单击条目 → 内容复制回剪贴板
- [ ] 右键固定 → 条目置顶带 📌 标记；固定条目不被清理
- [ ] 右键删除 → 条目消失
- [ ] 双击图片缩略图 → 弹出原图预览窗口（可缩放/关闭）
- [ ] 历史超过 500 条时最旧的未固定条目被清理
- [ ] 托盘「贴出剪贴板」：文本/图片贴到屏幕置顶
- [ ] 剪贴板为空时贴屏 → 气泡提示「剪贴板为空」
- [ ] 历史条目右键「贴屏」→ 内容以贴图置顶

## 6. 取色器

- [ ] 取色模式下移动鼠标，放大镜与 HEX/RGB 实时更新
- [ ] 单击复制 HEX 色值并退出
- [ ] `Esc` 取消取色，不复制
- [ ] 取色历史保留最近 10 个；点击历史色值可重新复制
- [ ] 取色历史重启后保留

## 7. 设置

- [ ] 热键自定义：点击输入框按新组合键 → 立即生效并保存
- [ ] 清空热键 → 禁用该热键，功能仅托盘/主面板可触发
- [ ] 热键冲突（两个功能设置相同组合）→ 拒绝并提示
- [ ] 开机自启开启 → HKCU `...\Run\CaoNiGeToolbox` 出现；关闭后移除
- [ ] 强调色切换（青绿/橙黄/紫罗兰）→ 全局 UI 即时刷新
- [ ] 禁用「取色器」→ 取色热键失效、主面板与托盘入口隐藏
- [ ] 剪贴板上限修改生效

## 8. 打包与运行

- [ ] `pyinstaller build.spec`（CNG_ONEFILE=1）构建成功
- [ ] 产物体积 ≤80MB
- [ ] 单文件 exe 在 Win10/Win11 可启动，功能正常
- [ ] 从 exe 运行时数据写入 `~/.cng-toolbox/`
