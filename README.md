# 草泥鸽工具箱 🐦

Windows 桌面工具箱（Python + PySide6，PyInstaller 单文件 exe）。

**纯本地运行 · 无网络依赖 · 无账号体系**

## 功能

| 工具 | 说明 | 默认热键 |
|------|------|----------|
| 📷 截图置顶 | 框选屏幕区域，截图即钉在屏幕上（贴图可拖动/缩放/右键菜单） | `Ctrl+Alt+A` |
| 📋 粘贴板 | 剪贴板历史（文本+图片、搜索、固定、一键复制、图片放大预览）+ 贴屏 | `Ctrl+Alt+V` |
| 🎨 取色器 | 屏幕取色，放大镜预览，单击复制 HEX 色值（含取色历史） | `Ctrl+Alt+C` |
| 📦 主面板 | 工具箱卡片主界面 | `Ctrl+Alt+P` |
| 🗑️ 关闭全部贴图 | 一键清理所有置顶贴图 | `Ctrl+Alt+Q` |

## 截图置顶

- 按截图热键 → 屏幕出现遮罩 → 鼠标框选 → 松开即生成置顶贴图，同时图片已复制到剪贴板
- 贴图支持：**拖动** / **滚轮缩放**（20%~500%，鼠标锚点）/ **右键菜单**（复制、点击穿透、保存到文件、关闭）/ **双击复制**
- 最多同时 20 张贴图；托盘菜单可一键关闭全部
- 贴图边框支持 6 种预设（无/细线/粗线/虚线/发光/圆角）+ 颜色/粗细自定义，在设置中随时切换，即时生效

## 粘贴板

- 常驻监听剪贴板，自动记录复制过的文本和图片（同内容去重）
- 历史面板：类型筛选（全部/文本/图片）、关键词搜索、单击复制、右键固定/删除/贴屏、双击图片放大预览原图
- 历史持久化（SQLite），默认保留最近 500 条，固定条目永久保留；重启不丢
- 图片体积超过 20MB 不记录（可配置）
- **贴屏**：把剪贴板文本/图片一键「贴」到屏幕置顶（托盘菜单「粘贴板 → 贴出剪贴板」，或历史条目右键「贴屏」）

## 取色器

- 按取色热键 → 全屏取色模式：放大镜 + 实时 HEX/RGB
- 单击复制 HEX 色值；Esc 取消
- 自动保留最近 10 个取色历史

## 设置

- **通用**：开机自启（写入 HKCU 注册表）
- **热键**：每个全局热键均可自定义（点击输入框按新组合键），清空即禁用；冲突检测
- **外观**：强调色（青绿/橙黄/紫罗兰）、贴图边框（预设 + 颜色 + 粗细）
- **剪贴板**：历史上限、图片体积上限
- **工具**：各工具启用/禁用开关（禁用后热键与入口联动隐藏）

## 开发

```powershell
# 环境要求：Python 3.11+
pip install -e ".[dev]"

# 运行
python -m cng_toolbox.main

# 测试
python -m pytest

# 打包（单文件 exe，输出 dist/草泥鸽工具箱.exe）
$env:CNG_ONEFILE = "1"
pyinstaller build.spec
```

## 数据目录

运行时数据保存在 `~/.cng-toolbox/`：

```
config.json           # 配置（热键/外观/开关等）
clipboard.db          # 剪贴板历史（SQLite）
images/               # 历史图片文件
color_history.json    # 取色历史
```

## 技术要点

- 全局热键：Win32 `RegisterHotKey`（零第三方依赖，冲突时托盘气泡提示）
- 截图：逐屏抓取 + 虚拟桌面拼接，支持多显示器与高 DPI
- 贴图：无边框置顶窗口，`WindowTransparentForInput` 实现点击穿透
- 剪贴板：`QClipboard.dataChanged` 监听 + 自身写入防回环
- 打包：PyInstaller `--onefile --noconsole`，目标体积 ≤80MB
